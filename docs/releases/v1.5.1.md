Skillscout Mod 1.5.1 helps you see what you install before your agents follow it, and adds plugins, skillset sharing and skill checks. It's the first release built and published by GitHub Actions, and it includes everything planned for 1.5.0.

- **Review downloaded skills**: skills from Library repositories show a Contents section with their scripts and the lines worth reading, such as a download piped to the shell, `sudo` or deleting from your home folder. Add to tool asks first when a downloaded skill has scripts or high-risk commands, and the skillset Apply preview marks them.
- **See changes before updating**: Re-download and Refresh from Folder show the commit and the added, changed and removed files, with anything flagged, before replacing the Library copy. Discover shows the commit you downloaded.
- **Plugins**: a new Plugins view lists the plugins installed in Claude Code, Codex and Cursor, with their skills and what they run on your Mac without asking: hooks, MCP and language servers, monitors and executables. It only reads them.
- **Problems**: each skill you can edit is checked against the Agent Skills specification, such as a missing description, a name that doesn't match its folder, or a description over 1024 characters.
- **Export and import skillsets**: right-click a skillset to save it as JSON with the Git repository each skill came from, and import it on another Mac.
- **Keep or replace**: when an agent already has a different copy of a skill, choose Keep existing or Replace with selected source. The old copy goes to the Trash and comes back if the install fails.
- **Sidebar**: a new Used once filter, every group can be collapsed, and registered local folders show under Sources before you import them.

Command line tool:

- `skillscout-mod skillset` lists, shows, applies, unassigns, exports and imports skillsets. Applying, unassigning and importing stop while the app is open.
- `skillscout-mod plugins` lists your plugins and what they run.
- `install`, `add` and `update` list scripts and high-risk commands and ask first. Without a terminal they need `--yes`.
- `update` now shows the changes and replaces the Library copy instead of running `git pull`, and `install --no-link` adds a repository without linking its skills.

## Install

Download `Skillscout-Mod-1.5.1.zip`, unzip it, and move **Skillscout Mod** to your Applications folder. It runs on macOS 15 or later, on Apple silicon and Intel Macs.

The app is ad-hoc signed and not notarized, so macOS warns the first time you open it. Allow it in **System Settings > Privacy & Security > Open Anyway**, or run:

```sh
xattr -dr com.apple.quarantine "/Applications/Skillscout Mod.app"
```
