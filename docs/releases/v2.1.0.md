Skillscout Mod is now **Quartermaster**: it checks the skills your coding agents follow before they follow them, with usage counted from your chats, a review of what each downloaded skill runs, and a preview of every repository update.

- **One version per agent.** When a skill comes in versions, say one for Claude Code and one for every other agent, a skillset's preview lets you pick the version each agent gets, or skip an agent. No agent ends up reading two versions, including through folders it shares with other agents.
- **Projects keep one version per skill.** You choose it for each project. The preview leaves out a change that would give an agent two versions, and warns when your home folder has a different copy (Claude Code uses its personal copy over the project's).
- **Exported skillsets keep those choices.** Import applies only exact matches and lists the ones it couldn't apply.
- **One-time download.** The new name comes with a new bundle ID, so Skillscout Mod can't install this update itself. Download Quartermaster below, then move Skillscout Mod to the Trash.
- **Your Library moves with you.** On first launch the Library moves from `~/.config/skillscout` to `~/.config/quartermaster`. A link stays at the old path, so older links and scripts keep working, and the links in your agents' folders point at the new one. Your data and settings come over from Skillscout Mod.
- **`quartermaster` and `qm`.** Choose **Install Command Line Tool…** again. It links `quartermaster`, `qm` and `skillscout-mod` into `~/.local/bin` or Homebrew's folder when either is on your `PATH`, asks for a password only for `/usr/local/bin`, and leaves a `qm` from another program alone.
- **Global in the sidebar.** All agents, Shared (`~/.agents/skills`) and each agent by name, with counts. Shared offers **Remove from Shared…**.
- **Search skills.sh** in Discovery, with results in relevance order, install counts, and one click to preview the repository.
- **New icon**, a ledger with a tab for each agent and a check mark.

## Install

Download `Quartermaster-2.1.0.zip`, unzip it, and move **Quartermaster** to your Applications folder. It runs on macOS 15 or later, on Apple silicon and Intel Macs.

The app is ad-hoc signed and not notarized, so macOS may warn the first time you open it. Allow it in **System Settings > Privacy & Security > Open Anyway**, or run:

```sh
xattr -dr com.apple.quarantine "/Applications/Quartermaster.app"
```
