Skillscout Mod 1.6.0 makes skillsets easier to manage and keeps key controls readable in smaller windows.

- **Rename skillsets** from Edit or the sidebar context menu. The app keeps their assignments and rejects empty or duplicate names.
- **Find work faster** with Dashboard, Discovery, Library, Global, Projects, and Skillsets in a clearer sidebar order. Projects and skillsets are sorted by name.
- **Use smaller windows** with wrapping skill titles and actions, wider Discovery source names, and project application sheets whose controls remain visible as content scrolls.
- **Inspect skills smoothly** with background detail inspection and a cached usage report that refreshes when its inputs change.
- **Explore updated defaults** in Discovery, including SwiftUI, diagram, and visual explanation skill sources.

## Install

Download `Skillscout-Mod-1.6.0.zip`, unzip it, and move **Skillscout Mod** to your Applications folder. It runs on macOS 15 or later, on Apple silicon and Intel Macs.

The app is ad-hoc signed and not notarized, so macOS may warn the first time you open it. Allow it in **System Settings > Privacy & Security > Open Anyway**, or run:

```sh
xattr -dr com.apple.quarantine "/Applications/Skillscout Mod.app"
```
