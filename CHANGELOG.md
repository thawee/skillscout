# Changelog

## Unreleased

### Changed

- Skillscout Mod is now **Quartermaster**, with the bundle ID `com.thawee.quartermaster` and version 2.0.0. Skillscout Mod can't update to it on its own; download it once. On first launch it moves the Library from `~/.config/skillscout` to `~/.config/quartermaster`, leaves a link at the old path, points the agents' links and saved paths at the new folder, and copies data from `~/Library/Application Support/Skillscout Mod` and settings from Skillscout Mod.
- The command is `quartermaster`, with `qm` for short. **Install Command Line Tool…** links both, keeps a `skillscout-mod` link for old scripts, and leaves a name another program installed alone. The release zip is `Quartermaster-<version>.zip`.
- The sidebar fits more: Global's agent rows fold under **Agents** (folded by default, opened when you select an agent), and the status panel is three short lines with per-agent message counts in its tooltip, so Skillsets and Ideas stay in view in a small window.
- In Global, each **Remove from…** action sits in the card of the copy it removes, under the agents that read it, instead of above the skill's details. The skill detail no longer repeats the toolbar's **Add skills…** and **Add to skillset**.
- Suggestions, Similar skills, Chat activity and each skillset show their own name in the window title instead of "Skills". Discovery's choices read **Git**, **Folders** and **skills.sh**, so none wraps. An empty Projects list says so in one line under its header. Agent badges are slightly tighter.
- Discovery's defaults are down to seven collections: Android, Anthropic, Matt Pocock, UI/UX Pro Max, Addy Osmani, SwiftUI and Archify. diagram-design, answer-me-with-html, architecture-diagram-skill and archpresent are no longer defaults, since Archify covers them. Sources you added yourself and repositories in your Library stay.

### Added

- **One version per agent.** Copies of a skill with different content are versions, and no agent may read two of them, counting the folders it shares with other agents. A skillset's **Apply…** preview offers **Choose versions…** to pick a version per agent, with live checks, and applying leaves out any addition that would give an agent a second version. **Add skills…** refuses such an add, names a new copy after the skill instead of its source folder, and repository linking skips and reports links it can't place. An agent that reads another agent's skills folder gets that agent's version, **Skip** leaves an agent without a skill, and **Show conflicting copies** reveals a conflict that already exists. `quartermaster skillset version <skill> [--to <tool> --use <n|none|skip>]` lists and sets versions. Per-agent choices are saved under `agentSources` and skips under `skippedAgents` in `state.json`.
- New app icon for the Quartermaster rebrand: a ledger with one tab per agent and a check mark, on an olive background, generated by `scripts/render-icon.swift`.
- Global is a sidebar section like Projects: **All agents**, **Shared** (`~/.agents/skills`), then each enabled agent by name, with counts. Shared lists the skills in that folder and offers **Remove from Shared…**. The agent chips above the Global list are gone.
- Added [Archify](https://github.com/tt-a1i/archify) to the default Discovery sources. Existing custom registrations for the same repository appear as one source.
- Discovery has a **skills.sh** choice that searches the [skills.sh](https://skills.sh) directory when you press Return, lists results in relevance order with install counts and their Discovery or Library status, and shows each result's details, skills.sh page, and other skills from the same repository. **Add Repository to Discovery** opens the repository searched for that skill, ready to preview and add to Library. Results stay while you browse repositories.
- Skills installed with `npx skills` show the repository they came from, read from the CLI's lock files, with **Show in Discovery**.

### Fixed

- Default and named branch previews clone one commit. This avoids the 60-second Git timeout caused by downloading a large repository's full history, including Archify's.
